# 🃏 Steam Card XMK

Кроссплатформенное приложение с открытым исходным кодом для автоматического фарма коллекционных карточек Steam (Steam Trading Cards) методом «фантомного» запуска игр через локальный клиент Steam (Steamworks API).

Работает без физической установки и запуска тяжелых игровых файлов — Steam считает игру запущенной и начисляет карточки.

---

## ⚡ Особенности
- **Безопасная авторизация:**
  - Вход по **QR-коду** через мобильное приложение Steam (Steam Guard) — без ввода логина и пароля в сторонних формах.
  - Поддержка резервного входа через сессионные cookies (`steamLoginSecure`, `sessionid`).
  - Локальное сохранение сессии и автопродление токенов.
- **Стратегии фарма:**
  - **Умная (Smart):** параллельный разгон игр с наигранным временем `< 2` часов (до 30 игр одновременно), после чего переход к последовательному дофарму по одной игре.
  - **Последовательная (Sequential):** классический фарм по 1 игре за раз (начиная с игр с наибольшим количеством наигранных часов для скорейшего дропа).
- **Автоматический мониторинг и автоотключение:**
  - Периодическая проверка страниц значков (`/my/badges/`) с защитой от rate-limit Steam.
  - Как только у игры остается `0` невыбитых карточек — фантомный процесс автоматически завершается (`SteamAPI_Shutdown`), и запускается следующая игра из очереди.
- **Интеграция с локальным Steam:**
  - Мониторинг статуса клиента Steam (автопауза при закрытии клиента и автовозобновление при его запуске).
  - Нативные воркеры с автозавершением дочерних процессов при выходе из основного приложения.
- **Удобный веб-интерфейс:**
  - Автоматически открывается в браузере при запуске (`http://127.0.0.1:47890`).
  - Поддержка русского и английского языков, живое обновление логов и статусов (SSE).

## 🚀 Быстрый старт (скачал и запустил в 2 клика)

### 🪟 Windows 10/11
1. Перейдите на страницу **[Releases](https://github.com/XOMAK2245/steam-card-xmk/releases/latest)** и скачайте `steam-card-xmk-windows-x86_64.zip`.
2. Распакуйте архив в любую удобную папку.
3. Убедитесь, что официальный клиент **Steam запущен**.
4. Запустите `steam-card-xmk.exe`. В браузере откроется интерфейс управления.
5. Нажмите **«Показать QR-код»**, отсканируйте его в мобильном приложении Steam (раздел Steam Guard) и нажмите **«Старт»**.

### 🐧 Arch Linux / Manjaro
**Через PKGBUILD:**
```bash
# Скачайте PKGBUILD со страницы релиза:
curl -LO https://github.com/XOMAK2245/steam-card-xmk/releases/latest/download/PKGBUILD
makepkg -si
steam-card-xmk
```

### 🐧 Ubuntu, Debian, Fedora, SteamOS и другие дистрибутивы Linux
1. Скачайте `steam-card-xmk-linux-x86_64.tar.gz` со страницы **[Releases](https://github.com/XOMAK2245/steam-card-xmk/releases/latest)**.
2. Распакуйте архив:
   ```bash
   tar -xvf steam-card-xmk-linux-x86_64.tar.gz
   cd steam-card-xmk-linux-x86_64
   ```
3. Запустите:
   ```bash
   ./steam-card-xmk
   ```

## 🛠️ Сборка из исходников

Требования:
- Go 1.22+
- GCC (`build-essential` на Ubuntu/Debian, `base-devel` на Arch)

```bash
git clone https://github.com/XOMAK2245/steam-card-xmk.git
cd steam-card-xmk

# Сборка под текущую ОС (Linux):
make linux

# Или под Windows:
make windows
```

Готовые бинарники появятся в директории `dist/`.

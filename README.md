# XMK Suite

**Ультимативный геймерский комбайн** — кроссплатформенное приложение с открытым исходным кодом, объединяющее автоматический фарм карточек Steam и автовыполнение квестов Discord с полной системой мульти-аккаунтов.

---

## Возможности

### Steam Cards — Фарм карточек Steam
- **Мульти-аккаунт:** Добавляйте несколько Steam-аккаунтов, переключайтесь между ними в одно нажатие. Отображаются никнеймы и аватарки.
- **Живой поиск:** Быстрая фильтрация списка игр по названию или AppID.
- **Безопасная авторизация:** Вход по QR-коду через мобильное приложение Steam (Steam Guard) или импорт cookies (`steamLoginSecure`, `sessionid`).
- **Стратегия Batch (по умолчанию):** Одновременный параллельный запуск всех доступных игр с карточками (до 32 игр) для максимально быстрого дропа.
- **Стратегия Sequential:** Классический последовательный фарм по 1 игре за раз.
- **Автомониторинг:** Периодическая проверка страниц значков с защитой от rate-limit Steam. При 0 карточек игра закрывается, запускается следующая.
- **Интеграция с клиентом Steam:** Автопауза при закрытии Steam и автовозобновление при запуске.

### Discord Quests — Автовыполнение квестов Discord
- **Мульти-аккаунт:** Управляйте несколькими Discord-аккаунтами (отображаются ник и аватар). Быстрое переключение немедленно загружает квесты нужного аккаунта.
- **Актуальный список и фильтрация:** Автоматическое исключение истекших квестов, отдельная секция для уже завершённых заданий и живой поиск по названию.
- **Выполнение квестов без игр и стримов:** Автоматическое прохождение заданий Play, Stream и Watch Video.
- **Максимальная маскировка:** Сигнатуры официального Desktop-клиента Discord, корректный `X-Super-Properties`, случайный джиттер heartbeat (27–33 сек), реалистичные задержки.
- **Последовательное выполнение:** Квесты выполняются строго по очереди — без шквала одновременных запросов.

### Единый самодостаточный бинарник
- Все библиотеки (`steam_api64.dll`, `libsteam_api.so`) и веб-интерфейс встроены в один исполняемый файл.
- Нативное окно WebView2 на Windows и Chromium `--app` на Linux.
- Двуязычный интерфейс (русский / английский) с живыми обновлениями через SSE.

## Быстрый старт

### Windows 10/11
1. Скачайте **один файл** [`steam-card-xmk.exe`](https://github.com/XOMAK2245/steam-card-xmk/releases/latest/download/steam-card-xmk.exe) со страницы **[Releases](https://github.com/XOMAK2245/steam-card-xmk/releases/latest)**.
2. Запустите `steam-card-xmk.exe`:
   - **Steam Cards:** убедитесь, что клиент Steam запущен, войдите по QR-коду и нажмите **«Старт»**.
   - **Discord Quests:** вкладка «Discord Quests» → добавьте токен → **«Выполнить все квесты»**.
3. Для выхода нажмите **«Выход»** или закройте окно.

### Ubuntu / Debian / Fedora / SteamOS
```bash
tar -xzf steam-card-xmk-linux-x86_64.tar.gz
./steam-card-xmk-linux-x86_64/steam-card-xmk
```

### Arch Linux / Manjaro
```bash
curl -LO https://github.com/XOMAK2245/steam-card-xmk/releases/latest/download/PKGBUILD
makepkg -si
steam-card-xmk
```

## Сборка из исходников

Требования: Go 1.22+, GCC

```bash
git clone https://github.com/XOMAK2245/steam-card-xmk.git
cd steam-card-xmk

# Linux:
make linux

# Windows (кросс-компиляция):
make windows
```

Готовые файлы появятся в директории `dist/`.

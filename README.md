# Steam Card XMK

Кроссплатформенное приложение с открытым исходным кодом для автоматического фарма коллекционных карточек Steam (Steam Trading Cards) методом «фантомного» запуска игр через локальный клиент Steam (Steamworks API), а также автономного автовыполнения квестов Discord (Discord Quests Auto-Completer).

Работает без физической установки и запуска тяжелых игровых файлов — Steam считает игру запущенной и начисляет карточки, а Discord засчитывает прогресс квестов в фоновом режиме.

---

## Особенности

- **Фарм карточек Steam:**
  - **Безопасная авторизация:** Вход по QR-коду через мобильное приложение Steam (Steam Guard) или импорт cookies (`steamLoginSecure`, `sessionid`).
  - **Стратегия Batch (по умолчанию):** Одновременный параллельный запуск всех доступных игр с карточками (до 32 игр одновременно) для максимально быстрого выбивания дропа.
  - **Стратегия Sequential:** Классический последовательный фарм по 1 игре за раз.
  - **Автоматический мониторинг:** Периодическая проверка страниц значков (`/my/badges/`) с защитой от rate-limit Steam. При `0` карточек игра мгновенно закрывается, и запускается следующая.
  - **Интеграция с локальным клиентом Steam:** Автопауза при закрытии клиента Steam и автовозобновление при запуске.

- **Discord Quests Auto-Completer (Автовыполнение квестов Discord):**
  - **Выполнение квестов без игр и стримов:** Автоматическое прохождение заданий типа Play, Stream и Watch Video в Discord.
  - **Максимальная маскировка и защита от детекта:**
    - Использование сигнатур официального Desktop-клиента Discord (Electron/Chrome).
    - Генерация корректного заголовка `X-Super-Properties` с платформой и версией.
    - Случайный джиттер отправки heartbeat-пакетов (27–33 сек) вместо роботизированного таймера.
    - Реалистичные задержки перед принятием (`enroll`) и клеймом наград (`claim`).
  - **Интерфейс квестов:** Наглядные карточки квестов с полосой прогресса, подробностями о наградах и кнопками запуска.

- **Единый самодостаточный бинарник:**
  - Все необходимые библиотеки (`steam_api64.dll`, `libsteam_api.so`) и веб-интерфейс встроены в один исполняемый файл.
  - Нативное окно WebView2 на Windows и Chromium `--app` на Linux.
  - Двуязычный интерфейс (русский / английский) с живыми обновлениями (SSE).

## Быстрый старт (скачал и запустил в 2 клика)

### Windows 10/11
1. Скачайте **один файл** [`steam-card-xmk.exe`](https://github.com/XOMAK2245/steam-card-xmk/releases/latest/download/steam-card-xmk.exe) со страницы **[Releases](https://github.com/XOMAK2245/steam-card-xmk/releases/latest)** (или `.zip` с этим же файлом).
2. Запустите `steam-card-xmk.exe` двойным кликом:
   - Для фарма Steam: убедитесь, что клиент Steam запущен, войдите по QR-коду и нажмите **«Старт»**.
   - Для квестов Discord: перейдите на вкладку **«Квесты Discord»**, сохраните ваш токен пользователя и нажмите **«Выполнить все квесты»**.
3. Для выхода нажмите **«Выход»** или закройте окно — все процессы будут безопасно остановлены.

### Ubuntu, Debian, Fedora, SteamOS и другие дистрибутивы Linux
1. Скачайте `steam-card-xmk-linux-x86_64.tar.gz` со страницы **[Releases](https://github.com/XOMAK2245/steam-card-xmk/releases/latest)** и распакуйте:
   ```bash
   tar -xzf steam-card-xmk-linux-x86_64.tar.gz
   ./steam-card-xmk-linux-x86_64/steam-card-xmk
   ```

### Arch Linux / Manjaro
```bash
curl -LO https://github.com/XOMAK2245/steam-card-xmk/releases/latest/download/PKGBUILD
makepkg -si
steam-card-xmk
```

## Сборка из исходников

Требования:
- Go 1.22+
- GCC (`build-essential` на Ubuntu/Debian, `base-devel` на Arch)

```bash
git clone https://github.com/XOMAK2245/steam-card-xmk.git
cd steam-card-xmk

# Сборка под Linux:
make linux

# Сборка под Windows (кросс-компиляция):
make windows
```

Готовые файлы появятся в директории `dist/`.
